# Archive

Files kept as a backup. **Nothing here is published to the live site** — the
leading underscore makes Jekyll skip this folder, and `_config.yml` excludes it
explicitly as a second layer.

Keep this folder if the domain changes or the site needs to be rebuilt from the
older assets.

## images/

| File | Note |
|---|---|
| `profile-photo-original.png` | Original 835x1238 portrait, 1020 KB. The live site now serves `assets/photoprofile/profile-photo.webp` (34 KB) with `profile-photo.jpg` (66 KB) as fallback. Re-export from this file if a larger or different crop is ever needed. |
